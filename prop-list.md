# What I'd actually build

If the goal is **“give an AI enough assets to author an -quality world without constantly making new meshes”**, I would *not* make this as 1,000 unrelated models.

The useful library is roughly:

| Library                          |     Target |
| -------------------------------- | ---------: |
| Architectural modular pieces     |       ~120 |
| Industrial/mechanical            |       ~120 |
| cargo/cover                      |        ~60 |
| urban/street                     |       ~100 |
| furniture/interiors              |       ~100 |
| military/IMC                     |        ~60 |
| vegetation/rocks                 |       ~100 |
| destruction                      |        ~70 |
| traversal/gameplay devices       |        ~40 |
| vehicles                         |        ~30 |
| signs/decals                     |       ~150 |
| **POI hero/setpiece assemblies** |   **~120** |
| **Total useful authored pieces** | **~1,070** |

Then those produce **many thousands of placed objects and prefab combinations**.

That is much closer to how  appears to have actually been authored than making one bespoke mesh per building. Respawn's own environment artists repeatedly describe shared props/assets alongside zone-specific world building. ([ArtStation][20])

And the **~120 POI-specific pieces are non-negotiable**: Planet Harvester, Skyhook, Phase Rift, Barometer, Downed Beast, Terraformer, Stasis Array, Energy Bank, Mega Fan, Shipyard Arcade ship, etc. Those are what stop procedural recombination of the ~900 generic pieces from turning every location into the same damned sci-fi industrial park.
