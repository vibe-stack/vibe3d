# vibe3d

Install production-ready Three.js models as source code you own.

```bash
bunx vibe3d init
bunx vibe3d add @scifi-kit/modular-wall
bunx vibe3d add @scifi-kit
```

Vibe3D resolves compatible registry packages, installs their models and shared
runtime files into your project, and preserves locally edited files by default.

```bash
bunx vibe3d --help
```
