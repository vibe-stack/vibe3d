# vibe-terrain

Install the preview-first Vibe Terrain skill into a project:

```bash
bunx vibe-terrain
# npm works too
npx vibe-terrain
```

The skill guides source-first Three.js WebGPU terrain authoring with procedural
recipes, game-ready compiled topology caches, multi-seed validation, and
biome-aware procedural materials.
